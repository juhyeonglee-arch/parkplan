# parkplan · 지하주차장 최적 배치

**버전 v1.6 (2026-11-04)**

[![시험](https://github.com/jh050720-coder/parkplan/actions/workflows/test.yml/badge.svg)](https://github.com/jh050720-coder/parkplan/actions/workflows/test.yml)

대지(지하 외벽선)·코어·경사로를 그린 도면 한 장을 넣으면, 주차장법 기준을 지키면서 **법정 주차대수가 가장 많은 지하주차장 배치**를 찾아 줍니다. 결과는 캐드 도면(DXF), 라이노 모델(3dm), 평면 그림(PNG), 층별 대수표(CSV)로 받을 수 있습니다.

## 이렇게 씁니다

1. 웹 주소를 엽니다. *(배포가 끝나면 여기에 주소를 적습니다)* 설치는 필요 없습니다.
2. 도면(DXF 또는 3dm)을 화면에 끌어다 놓습니다. 먼저 써 보려면 **예시 도면으로 해보기**를 누르세요.
3. 레이어마다 역할(대지경계·코어·경사로·장애물)을 확인합니다. 이름으로 짐작해 미리 골라 둡니다.
4. 층수, 주차 각도, 경사로 방식, 동선 가중치, 탐색 정도를 고르고 **배치 찾기**를 누릅니다.
5. 위쪽 탭에서 안 1~8과 대안을 비교하고, 오른쪽 **피드백**에서 손실이 나는 곳을 봅니다.
6. 경사로(파란 빗금)를 끌어 옮기면 그 자리 기준으로 다시 찾습니다. **경사로 자리 추천**은 벽을 따라 경사로를 옮겨 보며 대수를 비교합니다.
7. 오른쪽 아래에서 결과 파일을 내려받습니다.

### 도면 준비

닫힌 폴리라인(또는 원)으로 그립니다.

| 역할 | 레이어 이름 예 | 설명 |
|---|---|---|
| 대지경계 | `대지`, `경계`, `외벽`, `SITE` | 지하층 외벽 안쪽 선. 가장 큰 닫힌 선 하나를 씁니다 |
| 코어 | `코어`, `CORE`, `EV`, `계단` | 주차를 피하고, 장애인 구획을 가까이 둡니다 |
| 경사로 | `경사로`, `램프`, `RAMP` | 직접 그린 경사로(기본값). 짧은 변(입구) 앞 6m를 비우고 차로와 잇습니다 |
| 장애물 | `기계실`, `전기실`, `DA`, `피트` | 주차를 피할 곳 |

- 단위는 도면 설정을 읽고, 없으면 크기로 짐작합니다(화면에서 mm·cm·m 변경 가능). 결과 DXF·3dm은 입력 도면과 같은 단위·좌표라 원래 도면 위에 그대로 겹칩니다.
- DWG는 캐드에서 DXF로 저장해서 넣어 주세요.

### 결과 파일

| 파일 | 내용 |
|---|---|
| `…_배치.dxf` | 구획·차로·기둥·경사로·진행 방향을 레이어별로 그린 캐드 도면 |
| `…_모델.3dm` | 층별 레이어로 쌓은 라이노 모델 |
| `…_B1_평면.png`, `…_B2_평면.png` | 층별 평면 그림 |
| `…_층별대수.csv`, `…_요약.txt`, `…_통계.json` | 층별 대수, 법규 확인 목록, 피드백 |

## 어떻게 찾나 (요약)

1. 코어와 경사로는 그린 그대로 둡니다.
2. 격자 방향 × 주차 각도 × 확장형 줄 배치 × 벽 한 줄 조합을 기둥 없이 넓게 훑고, 상위 안 근처를 촘촘히 다시 봅니다.
3. 동선(경사로에서 각 구획까지 주행거리, 막다른 차로, 교차)을 평가해 연결 차로를 다시 고릅니다.
4. 기둥 줄을 동적계획법으로 골라(간격 5~9m) 기둥 때문에 잃는 구획을 최소로 합니다.
5. 자투리를 경형으로 채우고, 장애인·전기차 구획을 둡니다.
6. 순위: 법규를 지키는 안 중 `법정 대수 − 동선 가중치 × 동선 감점 × 층수`.

법규 기본값(구획 크기, 차로 너비, 경사로 너비·반경 등)은 화면의 **세부 설정**에서 바꿀 수 있습니다. 자세한 설명과 판별 변경 이력은 [docs/설명서_v1.6.md](docs/설명서_v1.6.md)에 있습니다.

## 자동 시험

커밋할 때마다 GitHub Actions가 **Windows와 Linux**에서 다음을 돌립니다. 결과 그림·화면 캡처는 각 실행의 **Artifacts**(시험결과-Linux / 시험결과-Windows)에 남고, PR에는 요약표와 그림이 댓글로 붙습니다.

| 시험 | 내용 |
|---|---|
| 설치·불러오기 | `requirements.txt` 설치 후 프로그램 불러오기 |
| 예제 입력 | `examples/예시_대지.dxf`를 명령줄로 넣어 DXF·3dm·PNG·통계가 다 나오는지 |
| 대수 기준 | 4개 대지(1층, 보통, 동선 가중치 0)가 기준 대수 이상인지: 예시 111, 사용자 대지 근사 82, 큰 대지 331, 자동 경사로 338 |
| 기능 | 구역별 차로 방향(예시 2개 층 220대 이상), 일방통행 흐름, 곡선 경사로 반경 검사 |
| 화면 서버 | 서버를 켜서 예시 도면 → 배치 찾기 → 내보내기 |
| 화면 클릭 (Linux) | 브라우저로 실제 화면을 눌러 보고 캡처, 자바스크립트 오류가 없는지 |
| 초대형 대지 (Linux) | 6.4만㎡·코어 10개·경사로 3개, 2,410대 이상 |

직접 돌리려면:

```bash
pip install -r requirements.txt pytest
python -m pytest tests            # RUN_HUGE=1 이면 초대형 대지까지
python -m parking_ai              # 화면 (http://127.0.0.1:8766)
python -m parking_ai examples/예시_대지.dxf --floors 2   # 화면 없이 결과 폴더에 저장
```

`tests/dev/`에는 개발 중 쓰던 개별 실험 스크립트가 있습니다(자동 시험에는 들어가지 않음).

## 작업 방식

- 개선은 브랜치에서 하고 PR로 올립니다. PR에는 바뀐 것, 시험 결과, 확인 그림을 담습니다.
- 시험이 통과하지 않은 PR은 합치지 않습니다.
- 판을 올릴 때는 `parking_ai/__init__.py`의 `VERSION`·`DATE`와 이 README 맨 위 줄을 같이 고칩니다.

## 저장소에 넣지 않는 것

- **개인 도면·대지 자료, 재배포가 금지된 자료**(예: 정밀도로지도)는 올리지 않습니다. 쓰는 사람이 화면에서 자기 파일을 지정합니다. `.gitignore`가 `examples/예시_대지.dxf`를 뺀 모든 DXF·DWG·3dm을 막습니다.
- **API 키 같은 인증 정보**는 저장소에 넣지 않고 GitHub Secrets나 화면 입력으로 받습니다.
- `examples/예시_대지.dxf`는 프로그램이 만든 가상 대지입니다. 시험의 '사용자 대지 근사'는 화면 캡처에서 어림잡은 좌표 숫자만 담고 있습니다.

## 쓰는 라이브러리

shapely 2, numpy, ezdxf, rhino3dm, matplotlib. 화면은 파이썬 표준 http.server로 띄웁니다. 글꼴은 Pretendard(SIL Open Font License, `parking_ai/web/vendor/fonts/PRETENDARD_LICENSE.txt`)를 함께 넣었습니다.
